# Sturdy Study · 과제 공유방

과제와 정답을 과목별·회차별로 공유하는 GitHub Pages 홈페이지입니다. 업로드 파일은 브라우저에서 암호화한 뒤 공개 저장소에 게시하며, 공개 GitHub API를 통해 자료실에 표시합니다.

## 누구나 자료 올리기

1. 홈페이지의 **자료 올리기**를 누르고 원본 파일과 12자 이상의 비밀번호를 입력합니다.
2. **암호화 ZIP 만들기**를 눌러 ZIP을 저장한 다음, 게시 양식을 엽니다.
3. 과목, 회차, 자료 종류를 입력하고 저장한 암호화 ZIP을 첨부해 제출합니다.
4. 비밀번호는 게시물에 쓰지 말고 자료를 받을 사람에게 별도로 전달합니다.

업로드에는 GitHub 계정 로그인이 필요하지만 저장소 쓰기 권한은 필요하지 않습니다. 원본 파일은 브라우저에서 Web Crypto API(PBKDF2와 AES-GCM)를 사용해 암호화되며, 비밀번호는 저장소나 게시물로 전송되지 않습니다. 공개 첨부 파일은 암호문 ZIP이므로 누구나 받을 수 있지만 비밀번호 없이는 원본을 열 수 없습니다. 내려받은 ZIP은 홈페이지의 **비밀번호로 열기**에서 선택하고 게시자가 알려 준 비밀번호를 입력해 복호화합니다.

원본은 20MB 이하로 선택해 주세요. 한글 문서는 PDF로 변환하면 편리합니다. 비밀번호를 잊으면 복구할 수 없으니 안전하게 보관하고, 자료를 받을 사람에게 비공개로 전달하세요. 공유 권한이 있는 자료만 올리고 이름·학번 등 개인정보는 가려 주세요. 기존에 암호화 절차 없이 올린 파일은 계속 공개 상태이므로 비밀번호 보호가 적용되지 않습니다.

## 홈페이지 구성

- 수학(유니미 정답 포함), 물리, 화학, 지성의 열쇠, 기타 교양 및 추가 과목
- 과목별 회차 자료 수와 과제·정답 다운로드 링크
- 최근 업로드 목록, 검색, 과목 필터
- 브라우저에서 암호화 ZIP 만들기와 비밀번호 복호화
- GitHub Pages 자동 배포

## 배포

`main` 브랜치에 반영하면 `.github/workflows/pages.yml`이 GitHub Pages에 자동 배포합니다. 새 파일 업로드와 공개 Issue 열기는 GitHub Issues를 사용합니다.
